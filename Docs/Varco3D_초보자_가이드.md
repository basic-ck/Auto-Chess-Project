# 바르코 3D 초보자 가이드 — 복사해서 붙여넣기만 하면 되는 버전

이 문서만 보고 따라 하면 됩니다. 어려운 용어는 쓰지 않았고, **프롬프트는 전부 완성된 문장**이라 그대로 복사해서 붙여넣으면 됩니다.

> 확인된 것 / 확인 못 한 것
> - 확인됨: 바르코 3D(https://3d.varco.ai/)는 로그인 후 **글(한국어·영어 모두 가능)** 또는 **이미지 1장**으로 3D 모델을 만들고, 몇 분 걸리며, **FBX·OBJ·GLB** 로 내려받을 수 있습니다.
> - 확인 못 함: 버튼의 정확한 이름·위치, 무료로 쓸 수 있는 횟수(크레딧)는 요금제와 화면 업데이트에 따라 다릅니다. 아래에서 `〔화면에 따라 이름이 다를 수 있음〕` 으로 표시한 곳은 비슷한 이름의 버튼을 찾아 쓰세요.

---

## 0. 먼저 알아둘 것 (1분)

1. **전부 만들 필요 없습니다.** 파일이 없는 칸은 게임이 자동으로 기본 도형으로 보여 줍니다. 만든 것만 넣으면 그 부분만 바뀝니다.
2. 만드는 것은 네 종류입니다.

| 종류 | 개수 | 어디에 넣나 | 어디서 만드나 |
|---|---|---|---|
| 맵 타일 | 8개 | `Map` 폴더 | 바르코 3D |
| 유닛 | 40개 (+소환 유령 1개) | `Units` 폴더 | 바르코 3D |
| 배경 | 선택 | `Environment` 폴더 | 바르코 3D (어려움, 건너뛰어도 됨) |
| UI 그림(골드·배지) | 선택 | `UI` 폴더 | **바르코 3D가 아님** — 그림 만드는 AI나 직접 그림 |

3. 순서는 **타일 → 유닛 → (나머지는 나중에)** 를 추천합니다. 가장 큰 변화가 먼저 보입니다.
4. 파일 넣는 위치: `프로젝트폴더/Assets/Resources/Visuals/` 아래의 `Map`, `Units`, `Environment`, `UI` 폴더. (Unity 메뉴를 한 번 누르면 폴더가 저절로 생깁니다. 6번 참고)

## 1. 준비물

- 바르코 3D 계정 (https://3d.varco.ai/ 에서 가입/로그인)
- 이 프로젝트가 열린 Unity
- 윈도우 탐색기 (파일 이름 바꾸고 옮기는 용도)

---

## 2. 에셋 하나를 만드는 방법 (모든 에셋이 똑같습니다)

1. https://3d.varco.ai/ 에 접속해 로그인합니다.
2. **프롬프트 입력창**에 아래 4번의 프롬프트 한 줄을 **통째로 복사해서 붙여넣습니다.** (한국어 그대로 OK)
3. **「3D 생성하기」** 버튼을 누릅니다. 몇 분 걸립니다.
4. 결과를 돌려서 봅니다. 아래 셋 중 하나라도 이상하면 같은 프롬프트로 **다시 생성**하세요.
   - 형태가 여러 개로 갈라졌다 / 배경이나 바닥이 같이 붙어 있다 / 너무 얇은 부분이 많다
5. 마음에 들면 **다운로드**에서 **FBX** 를 고릅니다. 〔화면에 따라 이름이 다를 수 있음〕
   - 옵션에 **폴리곤 수** 조절이 있으면 낮은 쪽(유닛 5천 이하)으로, **텍스처(색)** 옵션이 있으면 켭니다.
   - 압축 파일(.zip)로 받아지면 풀어서, `.fbx` 파일과 같이 있는 그림 파일(.png/.jpg)도 **같이** 옮깁니다.
6. 받은 파일의 **이름을 바꿉니다.** (이게 제일 중요합니다!)
   - 예: 수련기사 → `Unit_01.fbx` / 첫 번째 타일 → `Map_Tile_01.fbx`
   - 이름은 4번 표의 **「파일 이름」** 칸 그대로입니다. 대소문자·밑줄(`_`)까지 똑같이.
7. 이름을 바꾼 파일을 해당 폴더에 넣습니다. (5번에서 Unity에 연결하는 방법을 설명합니다)

> 팁: 한 번에 하나씩 만들고 바로 Unity에서 확인하면, 문제가 생겨도 어디서 틀렸는지 금방 찾습니다.

## 3. 첫 테스트: 딱 3개만 만들어서 전체 과정 확인하기 (추천)

처음엔 아래 3개만 만들어서 "내 컴퓨터에서 제대로 되는지" 확인하세요. 성공하면 나머지는 반복입니다.

| 만들 것 | 파일 이름 | 넣을 폴더 |
|---|---|---|
| 수련기사 (유닛) | `Unit_01.fbx` | `Units` |
| 아군 밝은 타일 | `Map_Tile_01.fbx` | `Map` |
| 바위 파수꾼 (유닛) | `Unit_05.fbx` | `Units` |

1. 4번의 **「Unit_01 수련기사」** 프롬프트로 만들고 → 다운로드 → 이름을 `Unit_01.fbx` 로 변경
2. 4번의 **「Map_Tile_01」** 프롬프트로 만들고 → `Map_Tile_01.fbx`
3. 4번의 **「Unit_05 바위 파수꾼」** 프롬프트로 만들고 → `Unit_05.fbx`
4. 5번 순서대로 Unity에 넣고 Play 합니다.
5. 확인할 것
   - 수련기사와 바위 파수꾼이 파란 큐브 대신 **새 모양**으로 나오는가
   - 그 유닛들이 **땅 위에 서 있는가** (공중에 뜨거나 땅에 박히지 않는가)
   - 아군 쪽 타일 일부(밝은 칸)가 **새 타일**로 나오는가 (나머지 칸은 기본 타일 — 정상입니다)

## 5. Unity에 넣고 확인하기

1. 이름을 바꾼 파일을 윈도우 탐색기로 아래 폴더에 복사합니다.
   `Auto_ChessB\Assets\Resources\Visuals\Units\` (유닛) / `...\Map\` (타일) / `...\Environment\` / `...\UI\`
   - 아직 이 폴더가 없으면 먼저 Unity 메뉴 **[AutoChess] → [비주얼 에셋 전체 자동 매칭]** 을 한 번 누르세요. 폴더가 생깁니다.
2. Unity 창으로 돌아가면 파일이 자동으로 읽힙니다. 잠깐 기다립니다.
3. Unity 메뉴 **[AutoChess] → [비주얼 에셋 전체 자동 매칭]** 을 누릅니다.
4. 아래쪽 **Console** 창에 이런 글이 나옵니다.
   - `유닛 3/40 ...` → 3개가 연결됐다는 뜻입니다. 숫자가 맞으면 성공.
   - `이름 규칙에 안 맞아 건너뜀: ...` → 파일 이름이 틀린 것입니다. 이름을 고치고 3번을 다시 누르세요.
5. 상단의 **Play** 버튼을 눌러 확인합니다.
6. 새 에셋을 추가할 때마다 **3번만 다시** 누르면 됩니다.

## 6. 문제가 생겼을 때

| 증상 | 원인과 해결 |
|---|---|
| 유닛이 **분홍색**으로 나온다 | 재질이 Unity URP와 안 맞는 경우입니다. Project 창에서 그 재질(Material)을 클릭 → Inspector 맨 위 **Shader**를 `Universal Render Pipeline/Lit` 로 바꾸고, **Base Map** 칸에 같이 받은 그림 파일을 끌어다 놓으세요. |
| 유닛이 **회색 단색**이다 | 그림 파일(.png/.jpg)을 `.fbx` 와 같은 폴더에 같이 넣었는지 확인하세요. FBX를 클릭 → Inspector의 **Materials** 탭 → **Extract Textures** 를 눌러도 됩니다. |
| 유닛이 **너무 크거나 작다** | 걱정 마세요. 게임이 높이를 자동으로 맞춥니다. |
| 유닛이 **공중에 뜨거나 땅에 박혀 있다** | 게임이 발 밑을 자동으로 맞춥니다. 그래도 이상하면 모델에 바닥 판이 같이 붙어 있을 수 있으니 "바닥 없음" 문구를 넣어 다시 생성하세요. |
| 유닛이 **옆으로 누워 있다** | FBX를 클릭 → Inspector → **Model** 탭 → **Bake Axis Conversion** 을 체크하고 Apply. 그래도 안 되면 알려 주세요(회전 옵션을 코드에 추가해 드립니다). |
| 메뉴를 눌렀는데 **개수가 0** | 파일 이름 오타일 가능성이 큽니다. `Unit_01` (대문자 U, 밑줄, 두 자리 숫자). `.fbx.fbx` 처럼 확장자가 두 번 붙지 않았는지도 확인하세요. |
| 타일 한두 개만 새 모양이라 **체스판이 어색하다** | 01+02, 03+04, 05+06 을 짝으로 만들어 넣으세요. |
| 게임이 **느려졌다** | 폴리곤이 너무 많은 모델입니다. 바르코 3D에서 폴리곤 수를 낮춰 다시 받으세요. |
| UI 그림이 **안 보인다** | `UI` 폴더에 넣었는지, 파일 이름이 `UI_Icon_Gold.png` 처럼 정확한지 확인하고 메뉴(5번의 3번)를 다시 누르세요. |
| 모든 걸 **원래대로** 돌리고 싶다 | 폴더 안 파일을 지우고 메뉴를 한 번 더 누르면 기본 도형으로 돌아갑니다. |
