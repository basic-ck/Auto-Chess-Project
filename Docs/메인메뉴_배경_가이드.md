# 메인 메뉴 배경·로고 가이드

메인 메뉴는 `Assets/Scripts/MainMenu.cs` 가 그린다. **이미지 파일이 없으면** 코드로 그린 임시 배경(노을 그라데이션 + 반짝이는 입자)과 글자 제목을 쓰고,
**아래 파일을 넣으면 자동으로 교체**된다(코드 수정 필요 없음). 넣고 Play(또는 MainMenu 씬 Game 뷰)에서 바로 확인.

| 파일 (위치: `Assets/Resources/Visuals/UI/`) | 용도 | 규격 |
|---|---|---|
| `Menu_Background.png` (jpg 도 가능) | 배경 일러스트 | **16:9, 1920x1080 이상**(2560x1440 권장). 비율이 달라도 화면을 꽉 채우고 넘치는 부분은 잘림 |
| `Menu_Logo.png` | 제목 로고(선택) | **투명 배경 PNG**, 가로 1200~1600px 정도. 있으면 글자 제목 대신 표시됨 |

- 크기·비율은 **원본 그대로** 들어가도록 자동 설정된다(`Assets/Editor/AutoChessMenuImageImporter.cs`).
- 배경은 아주 천천히 확대·이동하고, 위에 반짝이는 빛 입자가 떠오르며, 위아래 가장자리는 어둡게 깔린다.
- 버튼은 화면 **가운데 세로 정렬**이다. 일러스트의 중앙 아래쪽(가로 30%, 세로 45~80% 영역)에 버튼이 놓이니 **그 자리는 비워 두는 구도**가 좋다.

## 배경 일러스트 프롬프트 예시 (이미지 생성 AI용)
구도 요점: **가운데 위쪽은 제목, 가운데 아래쪽은 버튼**이 올라가므로 인물·핵심 장면은 **좌우 가장자리**에 둔다.

- 한국어:
  `16:9 가로 구도의 판타지 일러스트, 왼쪽에 작고 빛나는 푸른 정령들과 용사 기사들의 군대, 오른쪽에 거대한 돌 거인과 불꽃 거인이 서 있는 대결 장면, 가운데는 비워 두고 노을빛 하늘과 먼 산, 로우폴리 3D 스타일, 파스텔 톤, 따뜻한 보랏빛과 주황빛 조명, 부드러운 구름, 게임 메인 화면 배경, 글자 없음`
- English:
  `16:9 wide fantasy key art, small glowing blue spirits and knights on the left facing giant stone and fire colossi on the right, empty open center, sunset sky with distant mountains, low-poly stylized 3D look, pastel colors, warm purple and orange lighting, soft clouds, game main menu background, no text`

팁: 글자는 이미지에 넣지 말 것(제목은 게임이 따로 그린다). 마음에 드는 화풍이 정해지면 **나머지 UI 그래픽(버튼 바탕 등)** 도 같은 화풍으로 만들면 통일감이 좋다.

## 로고 만들기 (선택)
제목 「정령과 거인의 전쟁」(가제)을 로고 이미지로 만들 때는 **투명 배경**으로 뽑을 것. 확정 전에는 코드의 글자 제목(`GameTitle` 상수 한 줄)을 쓰면 된다.
