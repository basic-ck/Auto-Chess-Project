# 발표 대본과 영상 제작 안내

슬라이드 12장 기준 **약 7~9분** 분량(문장당 천천히 읽는 속도). 대본은 슬라이드 노트와 같다. `[ ]` 로 표시한 곳은 직접 채울 것.

## 슬라이드별 대본

### 1. 표지

안녕하세요, [발표자 이름]입니다. 오늘은 제가 만든 오토체스 게임 「정령과 거인의 전쟁」을 소개하겠습니다. 게임이 어떤 구조인지, AI로 만든 3D 에셋을 어떻게 게임에 넣었는지, 그리고 지금 어디까지 왔는지 순서대로 말씀드리겠습니다.

### 2. 게임 한눈에 보기

게임을 한 문장으로 말하면, 유닛을 사서 합치고 배치하면 나머지는 자동으로 싸우는 PvE 오토체스입니다. 라운드는 30개이고 목숨은 3개입니다. 유닛은 40종이고, 종족과 직업을 합쳐 시너지가 24가지입니다. 마나가 차면 자동으로 쓰는 액티브 스킬도 25종 있습니다.

### 3. 한 라운드의 흐름

한 라운드는 준비, 전투, 정산 세 단계입니다. 준비 단계에서 상점에서 유닛을 사고 리롤하고, 대기석의 유닛을 필드에 배치합니다. 전투 버튼을 누르면 유닛들이 알아서 싸우고, 마나가 차면 스킬을 씁니다. 전투가 끝나면 골드를 정산하고 다음 라운드로 넘어갑니다. 지면 목숨이 하나 줄고, 목숨이 0이 되면 게임 오버입니다.

### 4. 핵심 시스템

핵심 시스템은 세 가지입니다. 첫째는 합성입니다. 같은 유닛 세 개를 모으면 별이 오르고 능력치가 1.8배가 됩니다. 둘째는 시너지입니다. 서로 다른 유닛을 2종, 4종, 6종 모으면 종족과 직업별로 15%, 30%, 50% 보너스를 받습니다. 적에게도 똑같이 적용됩니다. 셋째는 경제입니다. 골드를 모아 두면 이자가 붙어서, 지금 쓸지 모을지 고민하게 됩니다.

### 5. 보스와 난이도

10라운드마다 보스가 나옵니다. 1스테이지는 바위 파수꾼, 2스테이지는 전방의 적을 전부 석화시키는 메두사 여왕, 마지막은 모든 적에게 뇌전을 내리는 제우스입니다. 보스는 크기가 1.8배이고 체력도 1.5배입니다. 난이도는 쉬움, 보통, 어려움 세 단계이고 적의 체력과 공격력 배율만 바뀝니다. 화면은 실제 제우스 보스전입니다.

### 6. 실제 플레이 화면

실제 플레이 화면입니다. 왼쪽이 준비 단계로, 상점에서 유닛을 사고 필드에 배치합니다. 오른쪽은 전투 장면으로, 체력바와 스킬 이펙트, 피해 숫자가 보입니다. 유닛 40종 모두 AI로 생성한 3D 모델이 연결되어 있습니다.

### 7. 제작 파이프라인

3D 유닛과 타일은 텍스트로 3D를 만들어 주는 바르코 3D로 생성했습니다. 그런데 결과물이 면이 50만 개, 파일 하나가 55메가바이트나 되어 그대로는 쓸 수 없었습니다. 그래서 Blender 스크립트를 만들어 겹친 점을 합치고, 표면을 매끈하게 하고, 면 수를 줄이고, 텍스처도 줄입니다. 그다음 Unity 메뉴를 한 번 누르면 재질이 자동으로 연결됩니다. 결과적으로 면 수는 50만에서 6천으로, 용량은 56메가에서 0.3메가로 줄었는데 게임 화면에서는 거의 차이가 없습니다.

### 8. 부딪힌 문제와 해결

제작하면서 부딪힌 문제를 세 가지만 말씀드리겠습니다. 첫째, 모델을 넣었는데 색이 안 나오고 회색으로 보였습니다. FBX 안에 색 텍스처가 들어 있는데 Unity가 재질에 연결하지 못한 것이어서, 텍스처를 꺼내 재질을 만들어 연결하는 메뉴를 만들었습니다. 둘째, 모델이 너무 무겁고 표면이 울퉁불퉁한 문제는 Blender 일괄 스크립트로 해결했습니다. 셋째, 유닛들이 서로 등지고 서 있는 문제가 있었는데, 모델의 앞 방향을 반대로 가정한 것이 원인이어서 바로잡았습니다.

### 9. 배경 테마 5종

전장 주변을 꾸밀 배경 컨셉을 다섯 개 만들어 비교했습니다. 투기장, 정령의 숲, 하늘 위 부유 섬, 화산과 얼음이 대립하는 지대, 별빛 신전입니다. 게임 중에 T 키를 누르면 바로 바뀌어서, 직접 눈으로 보고 하나를 고를 수 있습니다. 지금은 도형으로 만든 임시 소품이고, 확정된 테마의 소품만 3D로 만들 계획입니다. 위에서 내려다보는 카메라라서 하늘은 안 보이고, 바닥과 가장자리 소품이 분위기를 만든다는 점도 이 과정에서 알게 되었습니다.

### 10. 자동 시연·트레일러

트레일러 영상도 게임이 직접 촬영하게 만들었습니다. 실행할 때 데모 옵션을 주면 게임이 스스로 상점에서 유닛을 사고, 배치하고, 보스전까지 진행하면서 카메라가 움직입니다. 캡처 옵션을 주면 프레임을 일정한 간격으로 저장하기 때문에 컴퓨터가 느려도 영상이 끊기지 않습니다. 저장한 프레임은 Blender로 MP4로 합칩니다. 전체가 약 1분 안에 끝나기 때문에, 유닛 모델이 늘어날 때마다 다시 돌려서 영상을 갱신할 수 있습니다.

### 11. 현재 한계와 검증

솔직하게 현재 한계도 말씀드립니다. 첫째, 유닛 40종은 모두 3D 모델로 연결했지만, 배경 소품은 아직 임시 도형이고 테마도 하나로 정하지 않았습니다. 둘째, 난이도 검증입니다. 화면 없이 게임을 빠르게 돌리는 시험 모드를 만들어, 합성 우선으로 구매하는 단순한 봇으로 난이도마다 40판씩 측정했습니다. 처음에는 초반 구간과 최종 보스에서 막혀서 적 구성과 보스 체력을 조정했고, 조정 뒤에는 평균 도달 라운드가 쉬움 30, 보통 24, 어려움 20이며 보통에서 40판 중 9판을 클리어했습니다. 이 봇은 시너지를 쓰지 않기 때문에 사람은 더 멀리 갈 수 있을 것이고, 사람 기준 난이도는 직접 플레이하며 점검할 예정입니다. 셋째, 효과음은 넣었지만 배경음악은 아직 없습니다.

### 12. 마무리

이상으로 발표를 마치겠습니다. 정리하면, 30라운드 PvE 오토체스를 만들었고, AI로 생성한 3D 에셋을 Blender와 Unity 스크립트로 자동으로 게임에 넣는 파이프라인을 만들었습니다. 앞으로 배경 소품을 3D로 만들고, 사람 기준 밸런스를 점검하고, 배경음악을 넣을 계획입니다. 코드는 GitHub에 공개했고, 실행 파일과 트레일러는 Releases에서 받으실 수 있습니다. 감사합니다.

## 발표 영상(녹화) 만드는 방법

1. **PowerPoint/Google 슬라이드 쇼를 켜고 화면 녹화**: Windows 는 `Win+G`(게임 바) 또는 OBS Studio 로 슬라이드 쇼 화면 + 마이크를 녹화한다. (PowerPoint 라면 `슬라이드 쇼 > 쇼 녹화` 로 슬라이드별 음성을 바로 넣을 수도 있다.)
2. 위 대본을 소리 내어 읽는다. 슬라이드마다 끊어서 녹음하면 틀려도 그 장만 다시 찍으면 된다.
3. **6번(실제 플레이 화면)** 과 **10번(트레일러 모드)** 에서는 트레일러 영상(`Trailer/trailer.mp4`)을 중간에 잠깐 보여 주면 좋다.
4. 발표 영상 길이 목표: 7~9분. 제출 형식(mp4, 해상도 1080p)은 요구 사항에 맞출 것.

## 트레일러 영상 구성 (자동 시연 모드, 약 50초)

| 시간 | 장면 |
|---|---|
| 0~5초 | 메인 메뉴 (페이드 인) |
| 5~12초 | 오프닝: 전장 주위를 도는 카메라 + 제목 배너 |
| 12~25초 | 상점에서 유닛 구매, 리롤, 경험치, 필드 배치 |
| 25~35초 | 전투: 스킬 이펙트, 시너지 |
| 35~47초 | 최종 보스 제우스 전투 |
| 47~52초 | 엔딩 카드 |

다시 만드는 법: README 의 "자동 시연(트레일러) 모드"와 `Tools/make_trailer.py` 참고. 효과음은 자동으로 영상에 들어간다(촬영 중 기록된 소리 목록 사용). 배경음악은 쓰지 않기로 했다.
