# 프로젝트 현황 인수인계 (새 대화에서 이어갈 때 먼저 읽을 문서)

작성 시점: 2026-10-06 (메인 메뉴 씬 분리 반영). 가제: **정령과 거인의 전쟁** (코드의 `GameTitle` 상수 한 줄로 변경)

## 1. 한눈에 보기

- Unity 6 (6000.3.21f1), URP. 씬 2개: `MainMenu`(빌드 0번, 카메라 + `MainMenu` 컴포넌트) → `GameScene`(빌드 1번, 카메라·조명·볼륨뿐; 예전 `SampleScene` 이름 변경). 게임은 `[RuntimeInitializeOnLoadMethod]` 가 `sceneLoaded` 를 구독해 **GameScene이 로드될 때** 스스로 생성함. 에디터에서 전체 흐름을 보려면 MainMenu 씬을 열고 Play.
- 씬 이동: 메뉴 [게임 시작] → GameScene(난이도는 PlayerPrefs `AutoChessDiff` 로 전달) / 결과창 [메인 화면] → MainMenu.
- UI는 전부 IMGUI(OnGUI). 화면 글자 크기는 고정값(해상도 스케일 없음).
- 오토체스 PvE: 8×8 전장 + 1×8 대기석, 30라운드(1-1~3-10), 목숨 3, 보스는 10·20·30라운드.
- Git 백업 4개(로컬 전용). 큰 FBX(50MB 이상)는 `.gitignore` 로 제외됨.

## 3. 게임 규칙 (현재 값)

- 시작: 골드 10, 목숨 3, 레벨 1. 레벨 = 출전 한도(최대 10). 경험치표 `Need = {2,2,6,10,20,36,56,68,68}`, 라운드 종료 +2XP, 4G = +4XP.
- 상점 5칸, 리롤 1G, 레벨별 코스트 확률표 `Odds`. 구매 → 대기석(8칸) → 드래그/클릭으로 필드(아래 4줄). 전투 중 이동 불가(판매는 가능). 대기석이 가득 차도 즉시 합성되는 구매는 허용.
- 합성: 같은 유닛 3개 → 별 +1(스탯 ×1.8, 최대 3성). 판매 환급: 1성 100% / 2성 75% / 3성 70%.
- 시너지: 필드의 서로 다른 유닛 수 기준 종족 14 + 직업 10, 2/4/6종 = +15/30/50%(체력 또는 공격력). 적에게도 적용.
- 정산(`CalculateRoundIncome`): 기본(1-1~1-3은 2/3/4G, 이후 5G) + 이자(10G당 1G, 최대 5) + 승리 +1 + 연승(2~3: +1, 4~5: +2, 6↑: +3). 패배 시 기본+이자만, 연승 끊김.
- 난이도(적 체력·공격력 배율): 쉬움 0.85 / 보통 1.0 / 어려움 1.15. 준비 단계에서만 변경.
- 전투: 0.4초 틱, 최대 250틱(100초) 후 남은 체력 합이 큰 쪽 승리. 마나가 차면 스킬(액티브), 패시브 `Fx`, 액티브 `Sk` 25종.
- 적 편성은 `StageManager.Waves` 표(라운드별 `{유닛ID, 성급, 수량}`), 보스 `BossId/BossStar = {2,2,2}`, `BossHp = 1.3`, 크기 1.8배. 적 진형: 근접=z4, 암살자=z5, 원거리=z6, 사거리4+=z7. 적 암살자는 내 진영 맨 뒤 유닛으로 순간이동.
- 편의: 도움말(H/ESC, 첫 실행 1회 자동, PlayerPrefs `AutoChessHelpSeen`), 전투 배속 ×1/2/3(`ApplyTime()` 한 곳에서 `Time.timeScale` 관리), 포기 버튼+확인창, 결과창 `[다시 하기]`.

## 4. 밸런스 상태 (봇 기준, 평균 도달 라운드)

**2026-10-19 난이도 완화 후**, 개발용 시험 모드(`SpiritsAndGiants.exe -batchmode -nographics -sim 40 -logFile sim.log`, `AutoChessSim.cs`)로 난이도마다 40판 측정(봇: 합성 우선 구매·경험치·리롤·배치, 시너지 고려 없음):

| 난이도 | 평균 도달 라운드 | 클리어(40판) | 완화 전(12판) |
|---|---|---|---|
| 쉬움 | 29.8 | 24판 | 28.1 / 4판 |
| 보통 | 24.3 | 9판 | 16.5 / 1판 |
| 어려움 | 19.6 | 5판 | 8.3 / 0판 |

조정 내용: 1-4~1-7 적 수 줄임, 3-1 에서 시간 술사 제외, 3-10 호위 5→4, `BossHp` 1.5→1.3, 어려움 배율 1.25→1.15. 남은 낮은 구간(보통 기준): 3-8~3-10(56~66%), 1-7(79%). 로그 줄은 `[SIM]`.
봇은 합성 우선 구매·경험치·리롤·배치만 하는 단순한 봇이라 시너지를 노리지 못함 → 사람이 하면 더 멀리 갈 수 있을 것. 사람 기준 클리어 가능 여부는 **미확인**.

## 5. 남은 후보 (우선순위 순)

1. 사람 기준 난이도 점검: 봇 기준은 위 표대로 완화함. 직접 한 판 해 보고 필요하면 `Waves` 표만 조정.
2. 배경 테마 확정: 5개 테마 비교 후 하나를 고르고(나머지는 삭제 가능) 진짜 소품 4개 제작. 아직 모두 도형 임시 소품.
2-1. 편의: 단축키(스페이스 전투 시작 등), 효과음·배경음, 해상도에 맞춘 글자 크기, 메인 메뉴 꾸미기(배경 이미지·옵션 화면, 지금은 단색 배경 + 버튼만).
3. 연출 3단계: 사망·등장 연출, 카메라 연출, 효과음.
4. 에셋: 나머지 유닛 38개를 바르코에서 만들어 Blender 정리 스크립트로 처리(용량 문제는 스크립트로 해결됨). 형태가 뭉개지는 유닛은 이미지→3D 방식 또는 프롬프트 단순화(큼직한 소품, A자 자세)로 재생성. 3D 유닛 애니메이션은 아직 없음(모델 정지 상태 표시, 회전은 대상 쪽으로 돌아봄).
5. 가제 이름 확정(`GameTitle`), 플레이어 설정(회사명 `DefaultCompany`, 아이콘, 해상도), 코드 파일 분리.

## 6. 작업 방법과 주의점 (Claude에게)

- 테스트는 MCP `execute_code` 로 Play 중 리플렉션 호출(봇 하네스, 일회용 스크립트라 저장 안 됨). **설정 묶음마다 Play를 껐다 켜서** 돌릴 것(연속 대량 측정은 에디터 메모리 21GB로 멈춘 적 있음).
- 스크립트 컴파일 직후 곧바로 Play하면 재생 중 재컴파일로 정적 참조가 끊길 수 있음 → 컴파일이 끝난 뒤 Play(`AutoChessVisualManager.I` 는 자동 복구되게 고쳐둠).
- 스크린샷은 `Assets/Screenshots/` 에 저장됨 → 끝나면 파일을 지울 것. (작업 폴더가 그 폴더로 바뀌면 폴더 삭제가 안전 검사에 막힘)
- 캡처 화면은 640×360으로 줄어든 이미지이고 실제 파일은 약 1075×605.
- IMGUI 스타일(GUIStyle)은 생성 때 속성이 안 먹는 경우가 있어 **그릴 때마다 속성을 다시 지정**함.
- 창이 백그라운드이면 프레임이 거의 안 돌아 연출 확인이 어려움 → `Time.timeScale = 0` 으로 정지시킨 뒤 캡처하고 반드시 1로 되돌릴 것.
- 도움말 첫 실행 표시용 PlayerPrefs 키(`AutoChessHelpSeen`)와 난이도 키(`AutoChessDiff`)는 테스트 후 삭제해 둘 것.
- Play 중 씬 전환 테스트는 `SceneManager.LoadScene("GameScene")` 후 **프레임이 지난 뒤** 별도 호출로 상태를 확인할 것(같은 호출 안에서는 아직 안 바뀜).
- ExecuteAlways 컴포넌트(MainMenu 등)는 스크립트 재컴파일 뒤에도 비공개 필드 값이 남을 수 있음 → 텍스처·스타일 필드는 `[System.NonSerialized]` 로 표시해 둠. 이미지 파일을 새로 넣은 직후에는 Play 를 껐다 켜거나 씬을 다시 열어야 새 파일을 읽음.
- 씬 이름은 `AutoChess.GameScene`/`MenuScene` 상수와 일치해야 함(바꾸면 상수도 수정).

## 7. 발표 준비 상태 (2026-10-16)

- **빌드**: Unity 메뉴가 아니라 MCP/에디터 `manage_build` 로 `Builds/Windows/SpiritsAndGiants.exe` 생성 → zip(`Builds/SpiritsAndGiants_Windows.zip`). `Builds/`·`Trailer/`·`TrailerFrames/`·`RawModels/` 는 git 제외.
- **자동 시연/트레일러**: `AutoChessDemo.cs`. `SpiritsAndGiants.exe -demo -capture TrailerFrames -fps 30 -screen-width 1280 -screen-height 720 -screen-fullscreen 0` → 프레임 JPG → `Tools/make_trailer.py`(Blender) 로 MP4. 시연용으로 아군 보호(체력 하한·체력 증가)와 적 체력 증가를 넣어 승리하도록 연출함(실제 밸런스와 무관). 결과는 Player.log 의 `[DEMO]` 줄로 확인.
- **유닛 방향**: 모델의 앞은 +Z. 예외는 `AutoChess.YawFix(id)` (비행함대 폭격기 -90°). 새 유닛이 엉뚱한 방향이면 거기에 추가.
- **고친 게임 버그**: 30라운드(최종 보스)에서 지고 목숨이 남으면 31라운드로 넘어가 `Waves` 범위 오류 → 30라운드에 머물러 보스를 다시 상대하도록 수정.
- **빌드 오류 주의**: `Assets/VARCO_URP`(바르코 도구 패키지)의 에디터 전용 스크립트가 플레이어 빌드를 막아서 `VarcoLab.asmdef`(Editor 전용)를 추가함. 이 폴더는 git 에 없음.
- **발표 자료**: PPT 12장은 claude.ai 슬라이드 아티팩트(비공개). 대본은 `Docs/발표_대본_및_영상_제작.md`.
- **소리**: `AutoChessAudio.cs`(효과음만, BGM 은 사용자 요청으로 넣지 않음). 파일은 `Assets/Resources/Audio/SFX/`(다른 프로젝트에서 가져온 것이라 `.gitignore`로 제외, 없어도 동작). 공격음은 직업별(`AutoChessAudio.Attack`), 8초짜리 마법음은 앞 0.9초만 재생. 트레일러 촬영 중에는 소리를 `audio_events.tsv`로 기록 → `make_trailer.py` 가 영상에 합침. M 키로 음소거.
- **남은 일**: GitHub 공개(저장소 생성·커밋 이메일 정리·약관 확인), 트레일러 배경음악, 사람 기준 난이도 점검, 배경 테마 확정 후 소품 3D 제작.
