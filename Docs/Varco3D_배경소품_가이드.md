# 배경 테마 소품 가이드 (바르코 3D)

게임 안에서 **T 키 / 상단 [배경] 버튼**으로 5개 테마를 바꿔 가며 비교할 수 있다. 지금은 **도형으로 만든 임시 소품**이 들어 있고,
아래 파일을 만들어 넣으면 **자동으로 임시 소품 대신 진짜 3D 소품**이 나온다(파일이 없는 것만 임시로 남음). 테마 하나씩 만들어 비교해도 된다.

## 파일 이름과 위치
`Assets/Resources/Visuals/Themes/<테마키>/<테마키>_NN.fbx` (NN = 아래 표의 번호). 한 소품이 여러 곳에 크기·방향을 바꿔 반복 배치된다.

## 작업 순서 (유닛·타일과 같은 방식)
1. 아래 프롬프트로 바르코에서 만들고 FBX 다운로드 → `RawModels/Themes/<테마키>/` 에 `<테마키>_NN.fbx` 이름으로 저장 (Assets 밖)
2. 테마별로 Blender 정리 (프로젝트 폴더에서, 소품은 면 수 2500·매끈하게 0.3 권장):
```
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --python Tools/clean_units.py -- --src RawModels/Themes/Arena --out Assets/Resources/Visuals/Themes/Arena --tex Assets/Resources/Visuals/ThemeTextures --faces 2500 --smooth 0.3
```
   (`Arena` 자리를 Forest / Sky / Volcano / Night 로 바꿔 5번 실행)
3. Unity 메뉴 `AutoChess > 유닛 색상 텍스처 추출·적용` 실행 → 게임에서 T 키로 확인

## 프롬프트 요령 (실패를 줄이는 법)
- **가늘고 작은 부분이 없게** 굵고 단순한 덩어리로. 한 덩어리 오브젝트로, 바닥에 놓인 모양으로.
- 아래 프롬프트 끝의 공통 문구(`로우폴리 스타일, 플랫 셰이딩, 파스텔 톤 단색 텍스처, 단일 오브젝트, 흰 배경`)는 그대로 둔다.
- 마음에 안 들면 같은 프롬프트로 몇 번 다시 만들어 가장 깔끔한 것을 고른다.
